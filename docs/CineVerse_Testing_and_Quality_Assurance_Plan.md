## 1. Strategy
- **Test first** for every compiler stage: write the cases from the spec, then the code.
- **Golden files** freeze the output of the lexer/parser/IR/codegen for every benchmark item; any change shows as a diff that must be reviewed.
- **Two proofs** gate the project: behaviour preservation (compiled = baseline) and equivalence (optimized = unoptimized).
- **Runtime tests never need the parser**; compiler tests never need the model or index (layer rules).
- **Deterministic**: fixed seeds; no network in tests; toy catalogue and toy embeddings for unit tests.

## 2. Test Levels
| Level | Scope | Speed | Needs model/index |
|---|---|---|---|
| Unit | One function/module | < 5 s total per module | No |
| Golden | Stage outputs for every benchmark item | < 10 s | No (compiler) |
| Integration | `recommend()` end-to-end on toy catalogue | < 20 s | Toy embeddings |
| Gate | Preservation, equivalence, layers, determinism | < 2 min | Real catalogue + index (marked `@pytest.mark.full`) |
| System / demo | Streamlit checklist | Manual | Yes |

Run `pytest -q -m "not full"` during development; `pytest -q` before every commit that closes a step.

## 4. Golden Files
- Location: `tests/golden/{tokens,ast,ir,program}/<request_id>.json|txt`.
- Generated by `python -m tests.golden.regenerate --only <stage>`; never edited by hand.
- A golden diff in a PR must be explained in the commit message ("parser: OR now allowed in preference → EX15 AST changed").

## 5. Gate Tests
| Gate | Pass condition | Blocks |
|---|---|---|
| Preservation | 100% items equal | Roadmap step 10 |
| Equivalence | 100% items × rule sets equal | Step 11 and release |
| Layers | No forbidden import | Every commit |
| Determinism | Byte-identical IR and results on re-run | Release |
| Zero violations | No result violates a hard constraint | Release |

## 6. Fixtures and Data
| Fixture | Content |
|---|---|
| `toy_catalog` | 30 hand-written movies covering every genre, years 1950–2020, null year/rating cases, tags |
| `toy_embeddings` | Deterministic 8-d vectors (seeded) so search order is known |
| `registry_toy` | Registry built from `toy_catalog` |
| `full_ctx` | Real catalogue + index, skipped with a clear message if artifacts are absent |

## 7. Coverage and Static Checks
| Tool | Target |
|---|---|
| `pytest --cov=cineverse` (pytest-cov, dev only) | ≥ 90% lines in `compiler/`, ≥ 80% in `runtime/` |
| `ruff check` | No errors |
| `ruff format --check` | Clean |
| `mypy cineverse/compiler` (dev only) | No errors in compiler package |

## 8. Defect Management
- Each defect: GitHub issue with request text, expected vs actual, failing stage, trace attached.
- Severity: S1 wrong results / violated hard constraint / equivalence failure; S2 wrong diagnostic; S3 UI or wording.
- S1 blocks merging; fixed with a regression test named `test_regression_<issue>`.

## 9. Quality Gates (release)
- [ ] All tests green on a clean clone (Windows and one of macOS/Linux).
- [ ] Gates in §5 pass.
- [ ] Coverage targets met.
- [ ] Ruff clean.
- [ ] Demo checklist (Deployment and Runbook §6) passes.
